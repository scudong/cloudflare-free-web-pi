# 投研资料摘要

## 何时使用

出现以下任一情况时使用本技能：

- 用户给出多份研报、公告、财报、访谈或新闻，要求提炼要点。
- 需要围绕一个公司、行业或主题做资料综述。
- 需要区分「资料原文」「分析推断」「个人观点」。
- 需要把长报告压缩成一页决策摘要。

不适用：替用户做买卖决策、给出目标价、或把没有来源的猜测写成事实。

## 输入

必需：

- 研究问题：要看什么、为什么看、最终要支持什么判断。
- 资料来源：用户提供的文件、链接或正文。

可选：

- 时间范围：只看最近一个季度、一年或特定日期之后。
- 关注维度：收入、利润、份额、政策、竞争、估值。
- 读者：投资团队、业务负责人、客户。
- 期望结论形式：一页摘要、对比表、风险清单。

资料来源不足时，明确列出缺口；不要用常识补成事实。

## 输出原则

1. **结论先行**：开头三句话给出最重要的发现和不确定性。
2. **每个数字有出处**：标明资料名称、日期和口径。
3. **事实与推断分栏**：推断必须写依据和假设。
4. **正反证据都保留**：不能只挑支持结论的材料。
5. **口径一致**：跨资料比较时统一币种、周期和统计范围。
6. **未知显式化**：没有数据就说没有，不用模糊词掩盖。

## 工作流程

1. **定义问题**：把研究问题改写成 2–4 个可回答的子问题。
2. **盘点资料**：列出每份资料的来源、日期、类型和可信度；标记一手资料与二手解读。
3. **抽取事实**：逐份提取数字、时间、主体和条件，保留原文口径。
4. **交叉验证**：同一事实至少找两个来源；冲突时并列呈现并说明差异。
5. **形成判断**：每条判断写成「结论 + 证据 + 假设 + 反证」。
6. **识别风险**：列出会推翻结论的关键变量和观察指标。
7. **压缩结构**：按「结论—证据—分歧—未知—跟踪项」组织。
8. **自检**：核对每个数字能否回到来源，每个判断是否超出资料范围。

## 输出格式

```markdown
# <主题> 资料摘要

- 资料范围：<时间范围、资料数量、类型>
- 更新日期：<YYYY-MM-DD>
- 一句话结论：<最重要发现，附一句不确定性。>

## 核心结论

1. **<结论一>**：<两句话说明，含关键数字。>
2. **<结论二>**：<...>
3. **<结论三>**：<...>

## 关键数据

| 指标 | 数值 | 同比/环比 | 口径与来源 |
|---|---|---|---|

### <结论一>

- 事实：<可追溯到来源的陈述。>
- 推断：<由此推出的判断。>
```

## 证据分级

- **A 级**：监管披露、公司公告、经审计财报、原始数据。
- **B 级**：公司交流纪要、行业协会数据、可信媒体的一手报道。
- **C 级**：券商研报的预测、专家访谈的转述、二手解读。
- **D 级**：社交媒体、匿名消息、无法核实的传闻。

结论主要依赖 A/B 级证据；使用 C 级时标注「预测」；D 级只作为线索，不进入核心结论。

## 对比研究规则

- 对比公司时统一会计期间、币种和调整口径。
- 市占率说明分母是出货量、收入还是用户数。
- 增速说明是同比、环比还是复合增速。
- 估值指标说明是静态、动态还是前瞻，并写明预测来源。
- 政策影响说明生效时间、适用范围和过渡期。

## 处理冲突资料

1. 先确认是否是同一口径；口径不同则分别列示，不强行合并。
2. 口径相同但数字冲突时，优先采用更接近一手披露的资料。
3. 仍无法判断时，在正文并列两个数字，并写「待核」。
4. 不因为某份资料更长、更新或语气更确定就默认它正确。

## 质量检查清单

- [ ] 开头结论能在 30 秒内读完。
- [ ] 每个关键数字都有来源和口径。
- [ ] 事实、推断、观点没有混写。
- [ ] 至少列出两条反方证据或风险。
- [ ] 数据缺口和未知项明确。
- [ ] 跟踪指标可观察、可触发动作。
- [ ] 没有目标价、买卖建议或无依据的预测。

## 边界

- 本技能只做资料整理和分析辅助，不构成投资建议。
- 不篡改原始数据，不把预测值写成实际值。
- 不引用无法核实的内部消息作为核心证据。
- 涉及未公开信息时，提示用户遵守合规要求并停止展开。
