# 网页转 Markdown

给一个 URL，把网页正文取回来，去掉导航和广告，存成一份能直接阅读的 Markdown 文件。

## 什么时候用它

- 你看到一个值得保存的网页，想把它变成工作台里的 Markdown 文件。
- 你要把网页内容转给同事或放进资料库，但不想发一条会失效的链接。
- 你需要在离线环境阅读一篇长文，先把它抓下来再说。

## 工具与参数

只调用下面两个工具，参数名必须完全一致。

| 工具 | 参数 | 返回 |
|---|---|---|
| `web_fetch_page` | `{ "url": "完整的 http(s) 地址" }` | 页面标题加 Markdown 正文，单次最多 8000 字符 |
| `write_file` | `{ "name": "文件名.md", "content": "完整正文" }` | 写入结果，包含文件名和字符数 |

调用顺序固定：先 `web_fetch_page`，再 `write_file`。不要跳过抓取直接凭印象写内容。

## 执行步骤

1. **确认地址**：用户没给 URL 时先问；给的地址不是 http(s) 开头时，指出问题并让用户补全。
2. **抓取正文**：调用 `web_fetch_page`，参数写成 `{ "url": "<用户给的地址>" }`。
3. **检查结果**：返回内容以错误说明开头时，原样转告用户，不写文件。常见情况是网址不合法、网页搜索未开启、抓取失败或正文为空。
4. **清洗内容**：
   - 删除导航、面包屑、推荐阅读、评论区、页脚、cookie 提示和「点击展开」这类界面文字。
   - 保留页面标题作为一级标题；正文标题层级整体下移一级，避免出现多个一级标题。
   - 保留列表、表格、引用和图片说明；图片保留可访问的绝对地址。
   - 相对链接补成绝对链接，锚点链接保持原样。
   - 合并被网页排版拆断的句子，去掉多余空行；不改变原文用词。
5. **加来源头**：正文开头写一行来源和抓取日期，格式为「> 来源：<原始 URL> · 抓取于 <YYYY-MM-DD>」。
6. **生成文件名**：
   - 优先用标题里的英文和数字，转成小写，空格换成连字符，去掉标点和重音符号。
   - 标题全是中文或无法转写时，用 `page-<YYYYMMDD>-<HHmm>.md`。
   - 文件名最长 60 个字符，必须以 `.md` 结尾，不能包含斜杠。
7. **写入文件**：调用 `write_file`，参数写成 `{ "name": "<文件名>", "content": "<来源头 + 清洗后的正文>" }`。
8. **回报结果**：告诉用户文件名、字符数，以及是否发生截断。

## 写作规则

- 不编造网页内容。抓取失败的页面不能靠常识补写。
- 不改变原文的事实、数字和观点；可以删界面元素，不能改写句子。
- 正文里出现脚本、样式或内嵌框架时整段删除，不尝试解释它们。
- 页面是登录页、验证码页或错误页时，直接说明抓不到正文，不把提示文字当成文章保存。
- 8000 字符是单次抓取上限。返回内容明显在句子中间结束时，在文件开头标注「> 注意：本次抓取在 8000 字符处截断，正文可能不完整」，并告诉用户后续部分没有取到。
- 不把网页里的署名、版权声明删掉；它们属于正文的一部分。
- 文件名冲突时覆盖同名文件，并在回报里说明「已覆盖同名文件」。

## 输出格式

写入的文件按下面的结构组织：

```text
# <页面标题>

> 来源：<原始 URL> · 抓取于 <YYYY-MM-DD>

<清洗后的正文>
```

对话里的回报不超过三行：

```text
已生成 <文件名>，共 <字符数> 字符。
来源：<原始 URL>
<发生截断时写：正文在 8000 字符处截断，未取到的部分需要另想办法。>
```

## 边界情况

- **网页搜索开关关闭**：工具会提示去设置里开启；把这句话原样告诉用户，不要重试。
- **页面需要登录**：说明只能抓到登录墙，请用户提供已登录后保存的正文。
- **正文主要是图片**：说明没有可读文字，图片说明会保留，但不做图片识别。
- **页面极长**：先保存前 8000 字符，明确标注截断；不要分多次抓同一地址假装拿到了全文。
- **用户只要摘要**：仍然先落文件，再在对话里给三行摘要；摘要不能替代文件。
- **用户要分享链接**：这个技能只负责写文件；分享链接由另一个技能生成，不要在这里编造 URL。

## 示例对话

```text
用户：把 https://example.com/report 抓成 Markdown 存下来。
助手：调用 web_fetch_page，参数 {"url":"https://example.com/report"}。
助手：抓到标题和正文，已去掉导航、广告和页脚。
助手：调用 write_file，文件名 report-2026-10-22.md，正文带来源行。
助手：已生成 report-2026-10-22.md，共 6,240 字符，没有截断。
```
