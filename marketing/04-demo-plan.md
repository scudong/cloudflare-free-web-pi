# 公开演示方案

发布帖最大的转化阻碍是「点进来能不能用」。当前线上需要访问密码，所以要先定演示形态。

## 三个选项

| 方案 | 做法 | 风险 | 适合 |
|---|---|---|---|
| **A. 演示邀请码** | 新建一个 `demo` 用户，预置示例会话/文件/知识库，把邀请码放在帖子或评论区 | 任何人拿到码都能聊天，模型费用记在主人账上 | 想让人立刻体验 |
| **B. 录屏 / GIF** | 30–60 秒录屏：提问 → 工具调用 → 文件生成 → 分享链接打开 | 无费用风险；信息密度低于真机 | X、小红书首图/视频 |
| **C. 只读演示** | 新增「只读访客」模式，只能看预置会话与文件 | 需要开发；当前没有这个模式 | 长期挂在 README |

**建议：B 先发，A 作为私信/评论区的补充。** 公开帖只放录屏与仓库链接；有人明确想试，再给演示码，并定期换码。

## A 的执行清单

- [ ] DeepSeek 控制台设置消费上限 / 余额告警
- [ ] 新建 `demo` 用户，预置 1 个会话、2 个文件、1 篇知识库文档
- [ ] 演示码定期重置（用户管理页可一键重置）
- [ ] 帖子里写明「演示空间可能随时重置；请勿放敏感资料」
- [ ] 观察 `/api/version` 与 DeepSeek 用量，异常时删除 demo 用户

## B 的 45 秒分镜

| 秒 | 画面 | 旁白/字幕 |
|---|---|---|
| 0–5 | 首页 + 左栏「知识库」 | 这是一个只属于你的 AI 工作台 |
| 5–15 | 在知识库粘贴一段资料 → 保存 | 资料自动切块、建索引 |
| 15–25 | 聊天提问，回答引用资料 | 每轮自动检索，回答带出处 |
| 25–35 | Agent 写文件，右栏出现 Markdown | 它会把结果写成文件 |
| 35–45 | 点分享 → 复制链接 → 新窗口打开 | 带有效期、带主题的分享页 |

录制建议：1500×940 或 1440×900，浅色主题；鼠标移动放慢；不要录到真实用户名/资料。

## 发布节奏

1. 先发 X thread + 录屏（英文），仓库链接
2. 同一天发小红书第 1 篇（个人网站角度）
3. 48 小时后发小红书第 2 篇（团队空间），把评论区的演示码换一次
4. 一周后发第 3 篇（文件分享），附一次真实使用案例
