# 结论分享

把一段结论整理成 Markdown，写进工作台，再生成一个能直接发给别人的只读链接。

## 什么时候用它

- 你刚整理完一段结论，想把它发给同事，而不是复制一大段聊天文字。
- 你需要一个带格式的只读页面，对方不用登录也能打开。
- 你要把同一份结论同时发给多个人，希望链接有明确的有效期。

## 工具与参数

只调用下面两个工具，参数名必须完全一致。

| 工具 | 参数 | 返回 |
|---|---|---|
| `write_file` | `{ "name": "文件名.md", "content": "完整 Markdown 正文" }` | 写入结果，包含文件名和字符数 |
| `share_file` | `{ "name": "文件名.md", "ttlSeconds": 604800 }` | 分享链接、有效期说明；同一文件会复用未过期链接 |

`ttlSeconds` 可选，常用取值：`3600` 一小时、`86400` 一天、`604800` 七天、`2592000` 三十天、`0` 永久。用户没指定时不传，沿用设置里的默认有效期。

调用顺序固定：先 `write_file`，再 `share_file`。`share_file` 只能分享已经存在的文件。

## 执行步骤

1. **收拢内容**：把要分享的结论整理成一段完整文字。用户只给零散要点时，先归纳成标题、结论、依据、下一步四部分。
2. **检查敏感信息**：正文里出现密钥、密码、手机号、客户全名、未公开金额时，先提醒用户，等用户确认脱敏或明确要求保留再继续。
3. **确定文件名**：
   - 用内容主题加日期，例如 `credit-outlook-2026-10-22.md`。
   - 只用小写英文、数字和连字符，最长 60 个字符，必须以 `.md` 结尾。
   - 主题是中文且无法转写时，用 `note-<YYYYMMDD>-<HHmm>.md`。
4. **写入文件**：调用 `write_file`，参数写成 `{ "name": "<文件名>", "content": "<正文>" }`。
5. **生成链接**：调用 `share_file`，参数写成 `{ "name": "<同一个文件名>" }`；用户指定了有效期时加上 `"ttlSeconds": <秒数>`。
6. **读回结果**：从工具返回里取出完整 URL 和有效期。返回里出现「分享失败」时，把失败原因告诉用户，保留文件，不要编造链接。
7. **回报**：给出文件名、完整 URL 和有效期；URL 必须原样输出，不改写、不截断、不加反引号以外的包装。

## 正文格式

写入的文件按下面的结构组织，没有内容的段落直接省略：

```text
# <标题>

> 结论日期：<YYYY-MM-DD>

## 结论
<两到三句话>

## 依据
- <依据一>
- <依据二>

## 下一步
- <谁在什么时间前做什么>
```

## 写作规则

- 链接必须是工具返回的完整地址，包含协议和域名；不根据经验拼接，不省略路径。
- 不在文件里写访问密码、内部系统地址、个人联系方式；确有必要时先问用户。
- 分享是写操作。用户没有明确说「分享」「发链接」「转给别人」时，只写文件，不调用分享工具。
- 同一份内容重复分享时先调用 `share_file`，工具会复用未过期链接；不要为了拿新链接改文件名。
- 有效期按用户原话选择；用户说「永久」才传 `0`，没说就沿用默认。
- 文件写入失败时停止，不继续调用分享工具。
- 回报里不写「点击这里」这类依赖界面的说法，直接给 URL。

## 边界情况

- **用户只要文件不要链接**：只调用 `write_file`，告诉用户文件已在工作台。
- **用户要更新已分享的内容**：用同一个文件名重新写入，再调用 `share_file`；链接会复用，内容以最新文件为准。
- **分享失败**：原样转告失败原因，说明文件仍然保留，可以稍后重试。
- **内容很长**：先给结论和依据，细节放附录；单文件建议不超过两万字。
- **用户要求设置密码**：当前分享工具不支持密码，直接说明，不要承诺不存在的功能。
- **用户给了多个文件名**：一次只处理一个；需要多个链接时分次写入和分享，并分别回报。

## 示例对话

```text
用户：把刚才的结论整理成文件，发我一个七天的链接。
助手：整理成标题、结论、依据、下一步四部分，文件名 credit-outlook-2026-10-22.md。
助手：调用 write_file，写入 1,860 字符。
助手：调用 share_file，参数 {"name":"credit-outlook-2026-10-22.md","ttlSeconds":604800}。
助手：链接已生成：https://pi.example.com/s/abc123（7 天后过期）。
助手：文件也在工作台，文件名 credit-outlook-2026-10-22.md。
```
