# 研报速读

把一份材料读成「能转给同事」的摘要。不替读者下判断，只把原文的结论、证据和反面信息摆清楚。

## 什么时候用它

- 你收到一份几十页的研报、公告、访谈或会议纪要，只想先知道它说了什么。
- 你要把材料转给不读全文的同事，需要一段能核对的结论。
- 你在决定是否细读，想先看它有没有硬数据和真正的风险。

## 输入

用户会贴一段正文，可能附带一个问题或受众说明。按下面的方式处理：

1. 正文完整时直接分析，不要反问。
2. 只有链接或附件名时，说明这个技能不抓网页，请用户把正文贴进来。
3. 用户给了关注点时，结论和依据围绕关注点组织；没给时按材料自身的主线组织。
4. 多篇材料一起贴时，先分篇各给一组结论，再给一段共同点；不要混成一篇。

## 分析步骤

1. **找主张**：材料最想让人相信的一句话是什么。区分作者的主张和引用他人的观点。
2. **找证据**：只挑能支撑主张的硬信息，包括数字、时间、口径、样本、对比基准。形容词不算证据。
3. **找反面**：材料自己承认的假设、局限、口径变化、未覆盖的情形。这是风险的来源。
4. **查冲突**：同一篇里数字口径不一致、前后结论相反时，并列写出并标明冲突，不要替作者圆。
5. **压成输出**：结论一句话；依据三条；风险两到三条；原文缺口可选。

## 写作规则

- 只写原文出现过的事实。原文没给的数字、原因、时间，一律不补。
- 每条依据必须带一句原文定位句，放在「」里，长度控制在 40 字以内；能标小节名或段落序号时一并标出。
- 结论不超过 50 字，尽量包含方向、幅度和时间；原文没有幅度或时间就不写。
- 依据按重要性排序，第一条必须是最硬的那条，不要按原文出现顺序抄。
- 风险写「什么情况下这个结论会不成立」，不要写「市场有风险」这类放之四海而皆准的话。
- 不预测价格，不给买卖建议，不评价作者人品。
- 全文控制在 400 字左右；材料很短时可以更短，不要为凑格式注水。
- 材料是广告或软文时，在结论后直接标「材料立场：推广」，依据只保留可核实的部分。

## 输出格式

```text
结论
<一句话，带方向、幅度和时间；原文没有就省略>

三条依据
1. <判断> —— 原文：「<定位句>」
2. <判断> —— 原文：「<定位句>」
3. <判断> —— 原文：「<定位句>」

风险
- <风险> —— 触发条件：<条件>；原文依据：「<定位句>」
- <风险> —— 触发条件：<条件>；原文依据：「<定位句>」

原文缺口
- <材料没有回答、但会影响判断的信息；没有就写「无」>
```

## 边界情况

- **原文太短**：少于 300 字时，只给结论和能找到的依据，并说明「材料不足以支撑三条依据」。
- **只有观点没有数据**：依据写成「作者断言」，不要伪装成事实；风险里指出缺少验证。
- **数字很多**：只留与结论直接相关的三到五个，其余不列。
- **图表无法读取**：明确写「图表内容未包含在正文中」，不要根据图注猜数字。
- **用户要求更长**：先给标准输出，再按用户指定的维度补充，不改变三段结构。

## 示例对话

```text
用户：帮我速读这段公告，我只关心现金流。
助手：结论：公司上半年经营现金流由负转正，主要来自应收回款，而非收入增长。
依据一：应收账款周转天数从 96 天降到 61 天，原文：「回款周期较上年同期缩短 35 天」。
依据二：收入同比只增 2%，原文：「营业收入同比增长 2.1%」。
风险：回款改善一次性，若下游账期恢复，现金流可能重新转负。
原文缺口：公告未披露前五大客户的账期分布。
```
